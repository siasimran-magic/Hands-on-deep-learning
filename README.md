# Kaggle: Intro to Deep Learning

Exercises and notes from Kaggle's [Intro to Deep Learning](https://www.kaggle.com/learn/intro-to-deep-learning) micro-course, working through the core building blocks of neural networks using Keras/TensorFlow.

## Contents

| Notebook | Topic |
|---|---|
| `a-single-neuron.ipynb` | Linear units as the basic building block of neural networks; how a single neuron models a linear relationship |

*(More notebooks will be added here as the course progresses — deep neural networks, stochastic gradient descent, overfitting/underfitting, dropout & batch normalization, binary classification.)*

## About the course

Intro to Deep Learning covers the fundamentals of building neural networks with Keras and TensorFlow: from a single linear neuron up through multi-layer networks, training via SGD, and techniques to improve model generalization.

## Setup

Each notebook is self-contained and can be run directly:
```bash
pip install tensorflow pandas numpy matplotlib
jupyter notebook a-single-neuron.ipynb
```
