# Kaggle: Intro to Deep Learning

My worked exercises and notes from Kaggle's [Intro to Deep Learning](https://www.kaggle.com/learn/intro-to-deep-learning) micro-course, as I build up an understanding of neural networks from the ground up.

## Running locally

```bash
pip install tensorflow pandas numpy matplotlib
jupyter notebook
```
